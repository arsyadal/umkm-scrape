# 🧩 Google Maps Radius Finder & Lead Scraper Extension

Ekstensi Browser Chrome / Edge untuk mengukur radius wilayah (KM) secara visual langsung di situs Google Maps dan mengekstrak kontak UMKM yang berada dalam jangkauan radius.

---

## 🚀 Cara Install Ekstensi di Chrome / Edge

1. Buka browser **Google Chrome** atau **Microsoft Edge**.
2. Buka halaman ekstensi browser:
   - **Chrome**: Ketik `chrome://extensions` di address bar.
   - **Edge**: Ketik `edge://extensions` di address bar.
3. Aktifkan **"Developer mode" / "Mode pengembang"** di pojok kanan atas.
4. Klik tombol **"Load unpacked" / "Muat ekstensi tanpa kemasan"**.
5. Pilih folder: `C:\Users\muhammad.alg_ext\Documents\umkm-scrape\extension`
6. Ekstensi **Google Maps Radius Finder & Lead Scraper** siap digunakan!

---

## 🎯 Cara Penggunaan di Google Maps

1. Buka situs [Google Maps](https://www.google.com/maps).
2. Di pojok kanan bawah halaman Google Maps, akan muncul widget melayang **"🗺️ Radius Finder & Scraper"**.
3. Geser **Slider Radius (0.5 KM - 20 KM)** sesuai batas jangkauan yang Anda inginkan.
4. Klik **"🎯 Gambar Radius di Peta"** untuk mengaktifkan batas radius.
5. Klik **"📥 Ekstrak Kontak Usaha"** untuk mengunduh data prospek UMKM yang ada di layar ke file JSON.
